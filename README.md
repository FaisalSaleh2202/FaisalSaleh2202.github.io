# Faisal Portfolio

A beginner-friendly static portfolio built with Vite, React, Tailwind CSS, and React Router.

## Run locally

```bash
npm install
npm run dev
```

## Edit the content

All portfolio content is stored in `src/data/portfolioData.js`, including contact details, experience, projects, skills, education, and languages.

## Routes

- `/` — main portfolio
- `/experience` — professional experience
- `/projects` — selected enterprise projects
- `/skills` — technical skill groups
- `/cv` — printable CV page

Use the **Save as PDF** button on the CV page to open the browser print dialog and save the page as a PDF.
